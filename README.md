# 🧁 SweetCraft - Bakery Recipe & Cost Master

เว็บแอปพลิเคชันสำหรับจัดการสูตรขนมเบเกอรี่ ปรับสัดส่วนสูตรอัตโนมัติ คำนวณต้นทุน และสรุปรายการจ่ายตลาด โครงการนี้พัฒนาขึ้นโดยอ้างอิงสูตรขนม 12 รายการจาก [Google Sheets](https://docs.google.com/spreadsheets/d/1-XEWSnPdsUsVGVpT4H9aNOp0WitUraI0ob4dWO7sukw/edit?usp=sharing)

---

## ✨ ฟีเจอร์หลัก (Features)
- 🧮 **Interactive Recipe Scaling**: ปรับสูตรตามจำนวนเท่า (0.5x, 1x, 2x...), ตามจำนวนกระปุก/ชิ้นที่ต้องการ, หรือตามน้ำหนักวัตถุดิบที่มีอยู่
- 👨‍🍳 **โหมดเข้าครัว (Kitchen Mode)**: เช็คลิสต์ตวงวัตถุดิบทีละขั้นตอน พร้อมตัวจับเวลาในครัว (Kitchen Timer)
- 💰 **คำนวณต้นทุน & ราคาขาย (Cost Calculator)**: คำนวณต้นทุนต่อชิ้น/กระปุก บวกค่าแรง ค่าบรรจุภัณฑ์ และแนะนำราคาขายตาม Food Cost %
- 🏷️ **ราคา & ยี่ห้อวัตถุดิบ (Master Price List)**: กำหนดราคาต่อแพ็คและเปลี่ยนยี่ห้อวัตถุดิบได้ตลอดเวลา
- 🛒 **สรุปรายการจ่ายตลาด (Shopping List Planner)**: วางแผนผลิตหลายสูตรพร้อมกัน และรวมยอดวัตถุดิบที่ต้องซื้อ
- 🔒 **PIN Code Security Lock**: ระบบล็อกรหัสผ่านก่อนเข้าใช้งาน (รหัสเริ่มต้น: `1234`)

---

## 🛠️ วิธีการรันในเครื่อง (Local Setup)
```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรันโหมดพัฒนา
npm run dev

# 3. บิลด์สำหรับ Production
npm run build
```
